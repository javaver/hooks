## 🎬 60秒故事

阿嚎三天没吃饭，在66号公路盯上走鹃咻咻。他拿出Acme火箭滑板2000点火追击，咻咻轻松倒着跑，还90度转弯跑上悬崖晾衣绳。阿嚎直冲出悬崖，在空中定格举牌“哦豁”，然后垂直坠落砸出郊狼形大坑变纸片。咻咻递上仙人掌汁，阿嚎酸到变仙人掌，咻咻彩虹烟尘Beep Beep消失。

笑点：卡通物理延迟坠落、纸片人、脸部挤压变形、高科技道具低能操作。

## 🚀 如何生成最终视频（我的更好建议）

### 方案A：最快出片（推荐新手，1小时）
1. 打开 `final/index.html` 预览节奏
2. 打开 `video_prompts/AI视频生成提示词_可直接复制.md`
3. 去 **Luma Dream Machine** (https://lumalabs.ai/dream-machine) 或 **Kling 可灵** 或 **Runway Gen-3**
4. 每个Shot：上传对应分镜图作为首帧 + 粘贴提示词 + 设置时长（按脚本7s/8s/13s...）
5. 生成8段视频，下载后用 **剪映** 按时间轴拼接，加上BGM和我生成的beep音效

**一致性技巧：** 所有镜头提示词都加了全局角色描述，并用资产定妆照做参考图，可保持阿嚎和咻咻不乱变。

### 方案B：真3D管线（质量最高）
1. 资产图 → **Tripo3D / Rodin / Meshy** 生成3D模型
2. 导入 **Blender**，自动绑定 (Auto-Rig Pro)，做挤压拉伸绑定
3. 按视频脚本做动画，悬崖定格那段用定格帧
4. 用 **Cycles** 渲染，卡通Shader，Pixar风格
5. 后期合成

### 方案C：代码驱动3D（可交互）
用 Three.js + Rapier物理引擎，我已在index.html留好接口，可把资产图贴到3D模型上做实时追逐。

## 🎨 风格锁定

- 渲染：Pixar 3D卡通，Octane，柔和阴影，高饱和
- 角色：高度可挤压拉伸，毛发细腻但卡通，类似《疯狂动物城》
- 镜头：16:9电影感，大量跟随和低角度，公路片大远景
- 音效：无对白，仅拟声词+Beep Beep
