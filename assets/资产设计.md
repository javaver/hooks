# 资产设计 - 《沙漠快递》

## 1. 角色 Character

### 阿嚎 (Wylie the Coyote)
- **物种**：郊狼，拟人化
- **体型**：瘦长，2头身半卡通比例，大头小身，大耳朵，大尾巴，细腿
- **颜色**：主色蓝灰色毛发 #6B7B8B，肚皮米白 #FFF8DC，鼻子黑色，耳朵内侧粉色
- **特征**：永远疲惫但执着的眼睛，眼白多，瞳孔小，尾巴蓬松炸毛，胡子三根，经常出现蚊香眼
- **服装**：无，但可有Acme工具腰带
- **风格**：Pixar 3D卡通，毛发细腻但保持卡通感，类似《Wile E. Coyote》+《疯狂动物城》狐狸，高度可挤压拉伸
- **表情**：饥饿、震惊、得意、空中定格的“我完了”

### 咻咻 (Zippy the Roadrunner)
- **物种**：走鹃，拟人化
- **体型**：流线型，1.5头身，极细长腿，大脚丫，长脖子，小翅膀
- **颜色**：主色紫蓝色羽毛 #5D8AA8，头顶有三根黄色呆毛，胸口橙色羽毛，喙黄色，腿黄色
- **特征**：大眼睛闪光，自信微笑，尾羽像超级英雄披风，跑步时有蓝色速度残影
- **风格**：Pixar 3D卡通，光滑羽毛，类似《Looney Tunes》走鹃但更Q版，羽毛有微绒感
- **标志动作**：歪头，Beep Beep时头顶冒出“Beep!”文字泡

## 2. 道具 Props

### Acme火箭滑板2000
- 结构：复古木纹滑板 + 背后绑着巨大红色火箭引擎，侧面有压力表，顶部红色大按钮
- 贴纸：手写标签“绝对靠谱™”“小心烫”“Made by Acme”“时速500km/h?”
- 风格：做旧卡通，螺丝外露，冒黑烟，皮克斯式道具，3D渲染，材质有木纹+金属+橡胶
- 特效：喷口有火焰和黑烟

## 3. 场景 Environments

### 场景A：66号公路沙漠
- 元素：笔直双黄线公路消失在地平线，红色砂岩峭壁，夸张高大的仙人掌（有手臂状），公路牌“ROAD 66”，热浪扭曲空气，天空极蓝无云
- 时间：正午，硬光，高饱和度，卡通渲染
- 风格：3D动漫，类似《赛车总动员》沙漠，广角大远景

### 场景B：悬崖深谷
- 元素：垂直千米深的峡谷，底部有多个历史坑洞（郊狼形状），中间有一根细细的晾衣绳连接两岸，风化岩石
- 氛围：危险又搞笑，高度夸张

## 一致性要求
- 全片使用统一3D卡通渲染，Octane Render, Pixar风格，超清8K，柔和阴影
- 角色保持同一设计，避免真人或2D风格混入
