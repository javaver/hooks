# 《沙漠快递：阿嚎的复仇》- 1分钟3D动漫喜剧剧本

**类型：** 3D动漫 / 无对白喜剧 /  slapstick 追逐
**时长：** 60秒
**角色：**
- **阿嚎 (Wylie)**：瘦长的蓝色灰色郊狼，永远饥饿，发明家，表情丰富，眼睛会变成蚊香圈。致敬经典但原创设计。
- **咻咻 (Zippy)**：紫蓝色羽毛的走鹃，速度极快，自信又有点小贱，标志性叫声“咻-咻！BEEP BEEP!”

**世界观：** 美国66号公路沙漠，超现实卡通物理，Acme式道具。

---

### 故事梗概
阿嚎已经三天没吃东西，在沙漠公路上盯上了飞驰而过的咻咻。他掏出最新发明——Acme火箭滑板，试图抓住咻咻。结果却是被自己的发明和沙漠地形连环整蛊。

### 三幕结构

**第一幕：设伏 (0-15秒) - 饥饿的发明家**
沙漠正午，热浪扭曲。公路牌写着“Road 66 - 100 miles no food”。阿嚎肚子咕噜叫，拿着望远镜。远处一道蓝色闪电——咻咻以超音速掠过，带起一排仙人掌发型。咻咻停下，挑衅地对阿嚎“BEEP BEEP!”，然后瞬间消失。
阿嚎眼中燃起火焰，从背后掏出一个巨大红按钮的箱子，上面写着“Acme - 火箭滑板2000 - 绝对靠谱”。

**第二幕：追逐 (15-45秒) - 失控的追击**
阿嚎踩上火箭滑板，点火。滑板先是慢悠悠冒烟，然后“轰！”的一声以10倍音速冲出，直接把阿嚎的脸吹变形。
追逐开始：
1. 直线公路狂飙，咻咻在前面轻松慢跑，还回头做鬼脸。
2. 咻咻突然一个90度直角转弯，冲向悬崖边的细线。阿嚎刹不住，直直冲出悬崖。
3. 经典卡通物理：阿嚎在空中停滞，低头看脚下是万丈深渊，掏出一个小牌子写着“哦豁”。然后才坠落。

**第三幕：结局 (45-60秒) - 扁平的哲学**
山谷底部，阿嚎砸出一个完美的郊狼形状大坑，变成一张纸片，慢慢飘下来。
咻咻已经在坑边等着，递给阿嚎一杯仙人掌汁，然后再次“BEEP BEEP!”扬长而去，在沙漠上留下一道彩虹色的烟尘。
阿嚎喝了一口汁，瞬间被酸到脸皱成一团，变成了仙人掌形状。镜头拉远，沙漠恢复平静，只有天上Acme火箭滑板还在绕圈卫星般飞行。

**核心笑点设计：**
1. 反差萌：高科技道具 vs 低能操作
2. 物理梗：延迟坠落、纸片人、脸部挤压
3. 角色性格：咻咻的贱萌挑衅 vs 阿嚎的执着倒霉
4. 视觉奇观：3D动漫渲染，皮克斯风格毛发+公路片大远景

**情绪曲线：** 安静饥饿 -> 兴奋期待 -> 疯狂加速 -> 紧张 -> 悬空静止(笑点停顿) -> 爆笑坠落 -> 温馨贱萌收尾

**对白：** 全程无对白，仅有拟声词和“Beep Beep”“哦豁”
